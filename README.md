# Geliss-P Beddings Landing Page

## About the Project
A single-page business landing page created as part of my front-end web development learning journey. The website presents a bedding business concept and provides navigation to bedding product categories.

## Technologies Used
- HTML
- CSS

## Features
- Business-themed landing page
- Navigation menu
- Bedding product category buttons
- Background imagery and visual styling
- Business logo placement

## What I Learned
- Structuring a landing page using HTML
- Styling layouts and navigation with CSS
- Combining images, typography and colours to create a consistent visual theme
- Organising content around a business concept

## Learning Note
This is an early practice project. It reflects my learning process and the skills I was developing while exploring front-end web design.
